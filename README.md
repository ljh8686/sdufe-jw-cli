# sdufe-jw

山东财经大学教务系统（jw.sdufe.edu.cn）命令行查询工具。

**纯 HTTP 实现，不需要浏览器、没有验证码、不用装依赖。** 一条命令查成绩、绩点、课表、学分完成情况、考试安排。

```bash
node scripts/jw.mjs audit      # 绩点 + 各类学分要求 + 公选课明细，一条命令
node scripts/jw.mjs brief      # 一行摘要：第几周 + 今天有什么课 + 成绩概况
```

冷启动约 0.5 秒，热缓存约 0.1 秒（结果缓存 10 分钟）。

---

## 能查什么

| 需求 | 命令 | 输出 |
|---|---|---|
| 现在第几周 / 今天有什么课 | `node scripts/jw.mjs` 或 `brief` | 周次 + 当天课程 |
| 明天 / 某周课表 | `today` / `tomorrow` / `timetable --week 15` | 课程、教师、教室、单双周 |
| 整学期课表 | `timetable` | markdown 表格 |
| 某学期成绩 | `grades --semester 2025-2026-1` | 分数、学分、绩点、性质 |
| 全部成绩 / 只看挂科 | `grades --all` / `grades --failed` | — |
| 绩点、加权分、挂科统计 | `gpa` | 含挂科 + 官方口径两种 |
| **还差多少学分 / 公选课还差几个学分** | **`audit`** | 官方绩点 + 六类学分「要求/已修/在途/还需」+ 通选分类明细 |
| 培养方案、各学期计划学分 | `plan` | 表格 |
| 考试安排 | `exams` | 表格 |

完整说明：`node scripts/jw.mjs --help`，或看 [SKILL.md](SKILL.md)（含接口原理与踩坑记录）。

## 快速开始

**要求**：Node.js ≥ 18（不需要 `npm install`，零依赖）

```bash
git clone https://github.com/ljh8686/sdufe-jw-cli.git
cd sdufe-jw-cli

cp config.example.json config.json
# 编辑 config.json，填入学号和密码

node scripts/jw.mjs audit
```

`config.json` 长这样：

```json
{
  "user": "202400000000",
  "password": "你的密码",
  "base": "http://jw.sdufe.edu.cn"
}
```

不想把密码写进文件，也可以用环境变量（优先级高于 config.json）：

```bash
export JW_USER=202400000000
export JW_PASS='你的密码'
node scripts/jw.mjs audit
```

临时查别人的账号，一行搞定、不改任何文件：

```bash
JW_USER=202400000000 JW_PASS='密码' node scripts/jw.mjs audit
```

## 常见问题

**Q：校外能用吗？**
不能直连。教务系统只在校内网可达（IPv4 `210.44.128.158` / IPv6 `2001:250:581f:128::158`），校外需要先连学校 VPN。

**Q：会不会有验证码？**
目前登录页没有验证码。如果哪天加了，脚本会明确报「登录失败」，届时需要改 `login()`。

**Q：会不会被学校封号？**
正常频率（一天几次、查完就退）没有任何问题。脚本本身很克制：一次 `audit` 只有 4 个请求，且结果缓存 10 分钟。**请不要写循环轮询或高频爬取**，那既没必要也容易给教务系统添麻烦。

**Q：密码存在哪里？安全吗？**
存在本机 `config.json`（明文）或环境变量里。`config.json` 和 `.cache/` 都已写进 `.gitignore`，**不会被提交到仓库**。介意明文就用 `JW_PASS` 环境变量。

**Q：官方绩点和 `gpa` 算的为什么差一点？**
教务系统官方「平均学分绩点」**把挂科课程从分子分母里剔除**；`gpa` 的「含挂科」口径把挂科按 0 绩点算进分母。对外报数用官方口径，`gpa` 会把两种都打出来。

**Q：通选课页面「要求学分」列是空的？**
正常，本校不在那张表里填要求。要求以「学业完成情况」页的「通选」行为准，`audit` 已经处理好。

**Q：我是别的专业 / 别的年级，能用吗？**
只要教务系统还是这套强智 jsxsd，命令都能用，学分要求会按你自己的修读方案自动取。

**Q：为什么没有用浏览器自动化？**
不需要。登录只是 base64 + 表单 POST，所有数据页都能直接 HTTP 拿到，比开浏览器快 10 倍、也省资源。原理和每个接口的字段都写在 [SKILL.md](SKILL.md) 里。
